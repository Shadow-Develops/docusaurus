# API

CDN Manager v1.1.5 provides a versioned remote API for asset automation, uploads, delivery settings, and user grants. Start with the overview to create a scoped API key, then use the endpoint guides for your integration.

All public API routes are under `/api/v1` and use bearer API keys managed from `/admin/api`.
